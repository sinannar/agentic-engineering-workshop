## Research

Finish the path by observing the complete existing flows and identifying friction before reaching for visual polish.

```prompt
Use HVE Core Research to inspect the target flow from a user's perspective. Inspect interaction states, accessibility semantics, responsive behavior, and existing design conventions. List evidence-backed friction points.
```

## Plan

Use HVE Core Plan to choose improvements that reduce confusion or effort and can be verified with focused acceptance criteria.

```prompt
Plan a small UI/UX improvement set. For each change, state the user problem, proposed behavior, responsive and accessibility requirements, affected files, and validation approach.
```

## Implement

Deliver the approved interaction changes without changing unrelated visual shell behavior, and keep the HVE Core evidence trail intact.

```prompt
Implement the approved UI/UX changes with semantic markup, keyboard support, visible focus, and resilient states. Add or update tests where the project supports them.
```
